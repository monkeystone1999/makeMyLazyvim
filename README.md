## 🚀 빠른 시작
```vim
<leader>     " 모든 키바인딩 보기
<leader>ws   " 프로젝트 심볼 검색
<leader>xi   " LSP 진단
```

- ✅ C++ 자동완성 (`.h` / `.hpp`)

- ✅ CMake 통합
